긴급출동 일지 개인정보처리방침

시행일: 2026년 11월 18일

'긴급출동 일지'(이하 "앱")는 이용자의 개인정보를 소중히 다루며, 아래와 같이 처리합니다.

1. 수집하는 정보

  • 앱에 입력한 기록: 출동 날짜·시간, 보험사, 출동 종류, 금액, 거리(km), 메모. 이 정보는 이용자의 휴대폰 안에 저장됩니다.
  • 구글 계정 연동 시(선택): 구글 계정 이메일 주소(연결된 계정 표시용), 그리고 구글 드라이브의 이 앱이 만든 파일에 대한 접근 권한(drive.file).
  • 정품 인증: 기기 식별값으로 만든 머신 코드. 이용자가 직접 만든이에게 보낼 때에만 전달됩니다.

2. 이용 목적

  • 출동 기록의 저장·합계 계산·표시
  • 이용자가 원할 때 이용자 본인의 구글 드라이브에 기록을 시트로 저장·갱신하고, 다른 기기와 같은 기록을 쓰도록 동기화

3. 저장 위치와 제3자 제공

  • 기록은 이용자의 휴대폰과(연동한 경우) 이용자 본인의 구글 드라이브에만 저장됩니다.
  • 만든이나 다른 서버로 기록을 보내지 않으며, 제3자에게 제공·판매하지 않습니다.
  • 구글 API로 받은 정보는 위 목적 외에 사용하지 않으며, 광고에 쓰지 않습니다. 앱의 구글 사용자 데이터 사용은 Google API Services User Data Policy(Limited Use 요건 포함)를 따릅니다.

4. 보관과 삭제

  • 휴대폰의 기록은 앱 안에서 삭제하거나 앱을 지우면 삭제됩니다.
  • 구글 드라이브의 시트는 이용자가 드라이브에서 직접 삭제할 수 있습니다.
  • 구글 연동 해제: 앱 설정에서 로그아웃하고, 구글 계정의 서드파티 액세스에서 '긴급출동 일지' 권한을 삭제할 수 있습니다.
